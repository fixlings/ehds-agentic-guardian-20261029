ABOUT THE SYSTEM

How it works

The interface is a clear window onto the team's existing engine—not a substitute for its checks.

01

Interpret

The interpreter proposes a structured question. Local allowlists validate clinical codes and the query schema.

02

Guard

Deterministic rules determine whether the stated use is permitted. Forbidden purposes are rejected before aggregation.

03

Investigate

For permitted requests, the synthetic executor calculates results and the Evidence Agent checks scientific limitations.

04

Explain

Only backend-returned outcomes, non-suppressed results and audit references are displayed.

Important limitation

The current backend implements small-cell suppression, but we have not verified cross-query disclosure-history protection (for example, 72 − 71 = 1). This interface does not claim to close that gap. Roles in the demo are self-declared; no real identity or access verification is present.
